# Spanish Language Learning Quiz App

An iOS application designed to make language learning more interactive through image-based multiple-choice questions. The app focuses on Spanish vocabulary and uses visual prompts, answer validation, scoring, and progress tracking to create an engaging way to practice and reinforce new words.

## Features

- Image-based Spanish vocabulary questions
- Multiple-choice answers with answer validation
- Score and progress tracking
- Dynamic question, image, and answer updates
- Quiz completion and restart functionality
- Structured question data for organizing vocabulary, answer choices, images, and correct answers

## Built With

- Swift
- UIKit
- Xcode

## Project Purpose

I created this project as a way to combine my interest in programming with my interest in language learning. The idea was to explore how visual questions and interactive quizzes could make vocabulary practice more engaging than traditional self-study methods.

Using images alongside vocabulary questions gives users another way to associate a word with its meaning and encourages active participation while learning. The project was also designed with future expansion in mind, including additional languages, vocabulary categories, and new types of questions.

## Getting Started

### Requirements

- macOS
- Xcode
- iOS Simulator or compatible iPhone

### Running the App

1. Clone or download this repository.
2. Open `LanguageGameApp.xcodeproj` in Xcode.
3. Select an iPhone Simulator or connected iPhone as the run destination.
4. Click the Run button in Xcode to build and launch the app.

> This project is an iOS application and requires macOS and Xcode to build and run.

## About

The application uses a question model to organize vocabulary questions, images, answer choices, and correct answers. The main view controller manages the quiz flow, validates user selections, updates the score and progress, changes the displayed questions and images, and handles quiz completion and restarting.

The project demonstrates the use of Swift and UIKit to build an interactive iOS application while applying concepts such as object-oriented programming, UI interaction, application logic, and data organization.
